# S0n1c_404 Blog Starter

Dark Cybersecurity static blog for GitHub Pages. Built with plain HTML/CSS/JS; no Node, Jekyll, or build pipeline is required.

## Publish to the existing repository

1. Download and extract the ZIP.
2. Open `https://github.com/MostafaMohamed2030/MostafaMohamed2030.github.io`
3. Upload the **contents** of this folder (not the outer folder itself) into the repository root.
4. Commit to `main`.
5. GitHub Pages should deploy from `main` / root. Check Settings → Pages and Actions if needed.
6. Visit `https://mostafamohamed2030.github.io/`

## Pages
- `/` homepage with Dark Cybersecurity styling and English/Arabic toggle
- `/ctf/` CTF category
- `/ctf/abazon.html` Abazon article
- `/web-pentesting/`
- `/research/`
- `/projects/`

## Privacy
This public starter contains only the public article edition and redacted screenshots. Keep private notes, original ZIPs, unredacted captures, tokens, credentials, and raw exploit notes in a separate **private repository or encrypted local storage**. Do not upload those files to this public repository.

## Before publishing
- Confirm screenshot redactions are sufficient.
- Verify links and images after deployment.
- Remember that anything committed to a public repository can be copied or cached; deleting it later may not remove all copies.
