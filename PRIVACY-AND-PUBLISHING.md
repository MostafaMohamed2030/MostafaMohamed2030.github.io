# Publishing and privacy checklist

- Public repository = public forever in practical terms.
- Never commit the private ZIP, unredacted screenshots, session cookies, passwords, API keys, or private notes here.
- Keep a separate private repository (for example `S0n1c-Research-Private`) or encrypted local vault.
- Review every image before publication.
- The Abazon public article intentionally obscures the flag and omits a copy-paste exploit sequence.
- GitHub Pages serves public static content; it is not a private file vault.
